# Deprecated LHWR bandwidth-selection alias

`bw.hgwr()` is retained temporarily for older scripts. New code should
use [`bw.lhwr()`](https://byuzbasi.github.io/LHWL/reference/bw.lhwr.md).

## Usage

``` r
bw.hgwr(...)
```

## Arguments

- ...:

  Arguments passed to
  [`bw.lhwr()`](https://byuzbasi.github.io/LHWL/reference/bw.lhwr.md).

## Value

The result of
[`bw.lhwr()`](https://byuzbasi.github.io/LHWL/reference/bw.lhwr.md).
