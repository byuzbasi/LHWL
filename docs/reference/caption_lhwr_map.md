# Create a Caption for a Poincare Disk Map

Generate a concise caption-style interpretation for a map returned by
[`plot_lhwr_poincare_map()`](https://byuzbasi.github.io/LHWL/reference/plot_lhwr_poincare_map.md).

## Usage

``` r
caption_lhwr_map(object, digits = 3L)
```

## Arguments

- object:

  An object returned invisibly by
  [`plot_lhwr_poincare_map()`](https://byuzbasi.github.io/LHWL/reference/plot_lhwr_poincare_map.md).

- digits:

  Number of digits for reported correlations.

## Value

A character string.
