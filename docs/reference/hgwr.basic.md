# Deprecated HGWR model-fitting alias

`hgwr.basic()` is retained temporarily for older scripts. New code
should use
[`lhwr()`](https://byuzbasi.github.io/LHWL/reference/lhwr.md).

## Usage

``` r
hgwr.basic(...)
```

## Arguments

- ...:

  Arguments passed to
  [`lhwr()`](https://byuzbasi.github.io/LHWL/reference/lhwr.md).

## Value

The result of
[`lhwr()`](https://byuzbasi.github.io/LHWL/reference/lhwr.md).
