# Summarize an LHWR Model

Summarize an LHWR Model

## Usage

``` r
# S3 method for class 'lhwr'
summary(object, ...)

# S3 method for class 'hgwr'
summary(object, ...)
```

## Arguments

- object:

  An LHWR model object.

- ...:

  Unused.

## Value

An object of class `"summary.hgwr"` containing the original call, model
arguments, diagnostic values, and summary statistics for each local
coefficient surface.
